{%- comment -%} Alternative provider, used when `donate.provider` is "paypal". PayPal's official Donate SDK keeps the donor on this page and completes the gift in a popup, with card payment and monthly recurring included (recurring is enabled on the button itself, in PayPal). Note the cost: PayPal's confirmed-charity rate is 1.99% + $0.49 per donation, so the site copy claiming 100% of donations reach medical aid needs a caveat if this provider is used. Two working states, plus delegation: 1. `donate.paypal_button_id` set → inline SDK button, backed by an organization-specific paypal.com/donate?hosted_button_id=… link if the SDK is blocked. 2. only `donate.paypal_url` set → a plain styled link (a PayPal.me address, say). 3. neither → the shared "not switched on yet" card.
